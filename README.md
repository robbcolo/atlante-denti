# Atlante denti

Web app con l'atlante 3D dei 32 denti permanenti: tavolati occlusali, viste vestibolari,
visualizzatore 3D con sezioni (smalto, dentina, polpa, cemento) e vista dei canali.

## Installazione su iPhone e iPad
1. Apri il link della web app in **Safari**.
2. Tocca **Condividi** (quadrato con freccia) → **Aggiungi alla schermata Home** → **Aggiungi**.
3. Apri l'app dall'icona: si avvia a schermo intero. Al primo avvio scarica tutti i contenuti
   (circa 18 MB); quando in fondo alla pagina compare "disponibile offline" funziona anche senza rete.

## Aggiornamenti
Le nuove versioni si installano da sole: basta aprire l'app con la rete attiva (al massimo serve chiuderla e riaprirla una volta).
Immagini e modelli 3D già scaricati non vengono riscaricati.
